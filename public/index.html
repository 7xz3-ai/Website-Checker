How It Works

Paste one URL per line, then press Check Status.

  • Check redirects & Cloudflare — follows redirect chains and detects Cloudflare challenges, "Page Not Found", and the default nginx page.
  • Try all 4 variations — tests https://, http://, https://www. and http://www..
  • Detect unique redirects — flags redirects that resolve to a destination not seen by any other input URL.
  • Advanced Redirects (Longer) — follows up to 10 redirect hops instead of 3.

Status priority: Cloudflare patterns → "Page Not Found" / nginx default → HTTP status code.
