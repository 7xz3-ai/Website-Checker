How it works

Paste one URL per line, then press Run Check.

  • Check redirects & Cloudflare — follows redirect chains and detects Cloudflare challenges, "Page Not Found", and the default nginx page.
  • All 4 URL variations — tests https://, http://, https://www. and http://www..
  • Detect unique redirects — flags redirects that resolve to a destination not seen by any other input URL in the batch.
  • Advanced — follows up to 10 redirect hops instead of 3, with a longer timeout.

Status priority: Cloudflare patterns → "Page Not Found" / nginx default → HTTP status code.
